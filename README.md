# Wings by Quentin Launay et Regis Carrere

Ce projet est le rendu (en UDP ) du projet de multijoueur du groupe 1.

Il est composé en deux parties le src contenant le jeu et le coté client.

Et le dossier multijoueurs contient le server UDP et la gestion de la vérité.

Il ce base sur le Atari simple render.

La branche mouvement contient du code de test et d'essaie pour utiliser GLM et proposer de meilleurs mouvement.
